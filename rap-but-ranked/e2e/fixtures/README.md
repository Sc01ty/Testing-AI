# Test fixtures

| File | What it is |
| --- | --- |
| `Test Beat 92bpm.mp3`, `test-beat-140bpm.wav` | Synthetic drum loops made for the tests |
| `fake-voice.wav` | Synthetic syllable bursts. Chrome's fake mic plays it during Play tests |
| `tone-voice.wav` | A continuous 220 Hz tone (loops seamlessly), so gaps, overlaps and clicks in a joined vocal can be measured |
| `speech-voice.wav` | Synthetic speech generated for these tests with SpeechT5 + HiFi-GAN (MIT licensed), so on-device speech recognition has real words to hear |
