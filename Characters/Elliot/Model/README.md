# Elliot model

First visual prototype for NPC Package.

- Height: 1.87 m including hair (human body ~1.82 m)
- Scale: metres
- Up axis: Z
- Facing: -Y
- Mesh parts: 47
- Vertices: 2,911
- Triangles: 4,598
- Materials: 13
- Pose: neutral/nervous relaxed stance

`elliot.obj` and `elliot.mtl` are engine-neutral source assets. The separated named
parts preserve clean material boundaries and make the next rigging pass easier.
This is a visual prototype, not yet rigged or animated.
